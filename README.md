# Gradenix 🎓

AI-powered student performance prediction web app built with Flask and a Random Forest model.

## All files are at root level — just upload everything directly to GitHub, no folders needed.

## Setup

```bash
pip install -r requirements.txt
python run.py
```

App runs at `http://localhost:5000`

## Deploy (Railway / Render)

Start command: `gunicorn app:app`
